Compare current Bind-on-Equip auction prices across major EU realms without leaving Discord.

Add BOE Ledger to Discord

Discord command

/boe

  1. Select a BOE item.
  2. Select Normal, Heroic, or Mythic.
  3. Compare price, item level, stats, extras, and quantity by realm.

⚖️

Clear comparisons

One readable result per realm, with detailed variants available when needed.

🕒

Hourly prices

Auction data refreshes about once per hour and every result shows its update time.

🔒

Safe controls

Responses are public, but only the person who ran the command can use its menus.
